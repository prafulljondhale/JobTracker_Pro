# JobTracker-Pro
A responsive job application tracker with dashboard analytics, interview tracking, follow-up reminders, search, and Excel/CSV/JSON data management.
A modern and responsive Job Application Tracking System built using HTML, CSS and JavaScript.

JobTracker Pro helps job seekers manage their complete job search from one place.

## 🚀 Features

- 📊 Professional Dashboard
- 📝 Job Application Tracking
- 🏢 Company & Job Role Management
- 👨‍💼 Recruiter / HR Details
- 📧 HR Email & Contact Management
- 🎯 Application Status Tracking
- 🔄 Interview Pipeline
- 📅 Interview Date & Time Tracking
- 🔔 Follow-up Reminders
- 🔔 Notification System
- 📈 Application Analytics
- 📍 Applications by Location
- 📅 Applications by Month
- 🏢 Top Companies
- 📊 Interview Pipeline Analytics
- 🔎 Application Search
- 🌓 Dark Mode
- 📤 Export Data
- 👤 Multi-User Support
- 💾 LocalStorage Data Persistence
- 📱 Responsive Design

## 📌 Application Status

The application supports multiple job application stages:

- Wishlist
- Applied
- Shortlisted
- HR Screening
- Interviewing
- Technical Round
- Final Round
- Offer Received
- Accepted
- Rejected
- On Hold
- Withdrawn

## 📊 Dashboard

The dashboard provides an overview of:

- Total Applications
- Applied Applications
- Shortlisted Applications
- Interviews
- Offers
- Rejected Applications
- Follow-ups Due
- Response Rate

## 📈 Analytics

Analytics includes:

- Applications by Status
- Applications by Location
- Applications by Month
- Top Companies
- Interview Pipeline
- Job Search Insights

Analytics are calculated from the currently logged-in user's applications.

## 👤 Multi-User Support

JobTracker Pro supports multiple local users.

Each user has separate:

- Applications
- Interviews
- Follow-ups
- Notifications
- Analytics
- Settings

User data is stored separately using browser LocalStorage.

## 💾 Storage

The current version uses browser LocalStorage.

This means the application works offline without requiring a database.

> Note: LocalStorage-based authentication is intended for personal/offline/demo use and should not be considered production-grade authentication.
